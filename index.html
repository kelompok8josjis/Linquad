Sistem Persamaan & Pertidaksamaan Linear

Selamat datang di Linquad! Sebelum masuk ke masalah tiga variabel dan daerah pertidaksamaan, mari kita segarkan kembali ingatanmu tentang materi prasyarat.

🤔 Pertanyaan Pemantik

"Pernah patungan bayar makanan bersama teman-teman, tapi struk rinciannya hilang dan hanya tercatat total bayarnya saja? Bisakah matematika menebak harga tiap menu?"

Tujuan Pembelajaran Hari Ini:

  • Memodelkan masalah sehari-hari (nota belanja & anggaran usaha) menjadi SPLTV dan SPtLDV.
  • Menyelesaikan SPLTV dengan metode eliminasi–substitusi yang efisien dan memeriksa solusinya.
  • Menganalisis banyaknya solusi sistem persamaan (tunggal, tidak ada, atau banyak) dari hasil eliminasi.
  • Melukis daerah himpunan penyelesaian (DHP) SPtLDV pada bidang Kartesius untuk mengambil keputusan.

📸 Diskusi Kelas: Dua Jawaban Berbeda pada Soal 5b (−2x ≤ 6)

Perhatikan dua jawaban siswa tanpa nama berikut. Uji nilai x = 0 ke soal awal (−2x ≤ 6). Jawaban mana yang benar?

Jawaban Siswa A: x ≤ −3
Jika x = 0 diuji: −2(0) = 0 ≤ 6 (Benar), padahal 0 tidak ≤ −3!
Jawaban Siswa B: x ≥ −3
Jika x = 0 diuji: −2(0) = 0 ≤ 6 (Benar), dan 0 ≥ −3 juga Benar! Tanda dibalik karena dibagi −2.

Langkah 3: Substitusi & Hasil Akhir

Dari layar sebelumnya, kita mendapatkan SPLDV baru:
(4) x - y = 10
(5) x + 3y = 50

Jika kita kurangkan (5) dengan (4), variabel x akan hilang:
(x + 3y) - (x - y) = 50 - 10 ➔ 4y = 40 ➔ y = 10.
Gunakan nilai y=10 untuk mencari x, lalu gunakan x dan y untuk mencari z!
